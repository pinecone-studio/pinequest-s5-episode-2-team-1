# KUMA (PoC)

6–10-р ангийн хүүхдүүдэд зориулсан gamified хичээлийн апп. Өдөр бүр хичээлийн даалгавар хийж оноо, XP
цуглуулна; дараалал (streak) өсөх тусам оноо нь үржинэ. Оноогоороо дүрдээ хувцас авч, ижил түвшний
хүүхдүүдтэй бооцоотой real-time тулаан хийнэ.

- `mobile/` — Expo SDK 58 (Expo Go), expo-router, TypeScript, react-native-svg, expo-secure-store
- `api/` — Cloudflare Workers (Hono) + D1 + Durable Objects (`DuelRoom`, WebSocket Hibernation)
- `shared/types.ts` — API ба WebSocket-ийн гэрээ (хоёр тал `import type`-аар хуваалцана)

Апп-ын нэр (KUMA) `mobile/src/constants/brand.json`-д байна. Тоглоомын бүх тогтмол
`api/src/config/game.ts`-д, UI-ийн бүх текст `mobile/src/i18n/strings.ts`-д төвлөрсөн.

---

## 1. Шаардлага

- **Node 24** (Expo 57, wrangler 4, Vitest 5 нь Node ≥ 22 шаарддаг). `node -v` → `v24.x` байх ёстой.
  - macOS + Homebrew: `brew install node@24`, дараа нь `~/.zshrc`-д PATH нэмнэ (Apple Silicon:
    `/opt/homebrew/opt/node@24/bin`, Intel: `/usr/local/opt/node@24/bin`):

    ```bash
    echo 'export PATH="/opt/homebrew/opt/node@24/bin:$PATH"' >> ~/.zshrc
    ```

  - nvm ашигладаг бол repo дотор `nvm install && nvm use` (`.nvmrc` = 24).
- Утсан дээр **Expo Go** (SDK 58-г дэмждэг хувилбар).
- Компьютер ба утаснууд **нэг Wi-Fi**-д байна.

## 3. Демо ажиллуулах

### VS Code-оор (хамгийн хялбар)

1. Repo-ийн root хавтсыг нээнэ: `code .` (эсвэл File → Open Folder). "Trust" гэж асуувал зөвшөөрнө.
2. `Cmd+Shift+P` → **Tasks: Run Task** → **Демо эхлүүлэх**. Доод panel-д "API сервер", "Expo (QR код)"
   хоёр terminal зэрэг нээгдэнэ.
3. "Expo (QR код)" terminal дахь QR-ийг утсаараа уншуулна.
4. Зогсоохдоо terminal бүрт `Ctrl+C` (эсвэл `Cmd+Shift+P` → **Tasks: Terminate Task**).

Task бүр Homebrew-ийн Node 24-ийг өөрөө PATH-ийн урд тавьдаг. Харин VS Code-д **гараар нээсэн terminal**
macOS-ийн login shell тул `/etc/zprofile` (path_helper) PATH-ийг дахин эрэмбэлж системийн хуучин Node-ийг
сонгож болзошгүй ("Wrangler requires at least Node.js v22"). Ийм бол 1-р хэсгийн `~/.zshrc` мөрийг нэмээд
terminal-аа шинээр нээнэ. Бусад task: "Бот тоглогч", "Асуултын сан сэргээх", "Сурах бичиг оруулах", "Шалгалт".

### Terminal-аар

Гурван terminal (`node -v` → `v24.x` байх ёстой):

**1) API**

```bash
cd api
npm run dev
```

`0.0.0.0:8787` дээр асч, `http://<компьютерийн LAN IP>:8787` гэж хаягаа хэвлэнэ.

**2) Асуултын сан** (сервер ажиллаж байхад)

Шалгаж цэвэрлэсэн 315 асуулт `api/seed/questions.json`-д git дотор хадгалагдсан. Local DB хоосон
бол (шинэ компьютер, `db:reset`-ийн дараа) нэг командаар сэргээнэ:

```bash
cd api
npm run questions:import
```

Сурах замын шат бүр тухайн хичээлийн хуудасны бодлогыг авдаг. Математик 6-ын 63 хичээл тус бүрт 10 бодлого
(630, `api/seed/lesson-questions.json`, `bookRef` = хичээлийн хуудас) бэлэн тул эдгээр хичээл Gemini-гүйгээр эхэлнэ:

```bash
npm run lessons:import
```

Асуулт нэмэх бол Gemini-ээр (хослол бүрийг 40 хүртэл):

```bash
npm run seed:questions -- --model gemini-3.8-flash,gemini-3.6-flash,gemini-3.5-flash-lite
```

Free tier-ийн квот бага тул нэг хүсэлтэд 10 асуулт үүсгэж, эхний загварын өдрийн квот дуусах эсвэл
ачаалалтай (503) үед дараагийнх руу автоматаар шилжинэ. `--tier 1`, `--subject mongolian`,
`--parallel 2` гэж шүүж болно. Шинээр нэмсэн асуултаа шалгасны дараа `npm run questions:export`-ээр
`seed/questions.json`-оо шинэчилнэ. LLM-гүйгээр туршихад хослол бүрт 6 бэлэн асуулт оруулдаг
`npm run seed:fixtures` бий.

**3) Апп**

```bash
cd mobile
npx expo start
```

Утсаараа QR уншуулна. Апп API-ийн хаягийг Expo-ийн host IP-ээс автоматаар (`http://<IP>:8787`)
гаргана. Нэвтрэх дэлгэцийн доор `✓ Сервертэй холбогдлоо · http://…` гэж харагдвал холболт зөв.
Хаягийг гараар тогтоох бол `mobile/.env` файлд `EXPO_PUBLIC_API_URL=http://192.168.x.x:8787`
гэж бичээд `npx expo start -c`-ээр дахин асаана.

**Демогийн өмнө.** Local DB одоо цэвэр: хэрэглэгч байхгүй, асуултын сан шалгагдсан. e2e тест
туршилтын хэрэглэгчид үүсгэдэг тул демогийн өмнө ажиллуулахгүй байх нь дээр. `npm run db:reset` бүх
хэрэглэгч, асуулт, сурах бичгийн санг устгадаг тул хийсэн бол дараа нь заавал `npm run questions:import`
(сурах бичиг оруулсан бол `npm run books:import` ч) ажиллуулна.

## 4. Демо сценари (хүлээн авах шалгуур)

1. Хоёр утас QR уншуулж, 7-р анги ба 6-р анги гэж бүртгүүлнэ. Хоёулаа **Түвшин 1**, 50 оноотой эхэлнэ.
2. Хоёулаа нэг даалгавар хийнэ (5 асуулт). Асуулт бүрийн дараа зөв/буруу болон тайлбар гарна.
   Төгсгөлд оноо, туршлага (XP) нэмэгдэж, 🔥 дараалал 1 болно.
3. А **Тулаан** tab → Математик → бооцоо. Онооны 20%-иас их тоо оруулахад улаан анхааруулга гарч товч
   идэвхгүй болно; сервер ч мөн татгалзана. Сонгосон хичээлээр хэн нэгэн хүлээж байвал "Математикаар 1
   хүүхэд тулаан хүлээж байна" гэж гарч, тэр тулаан жагсаалтын эхэнд тодорч харагдана.
   **Хэнтэй тулах вэ?**: «Бүгдтэй» = ижил түвшний бүх хүүхдийн лобби дээр гарна, «Найзтайгаа» = лобби дээр
   гарахгүй, зөвхөн кодоор орно. Сорилт бүр 6 оронтой **урилгын кодтой** («Кодоо илгээх» товч).
4. Б лобби дээр (3 сек тутам шинэчлэгдэнэ) сорилтыг **Нэгдэх**, эсвэл **Кодоор орох** хэсэгт А-гийн кодыг
   бичнэ → хоёулангийнх нь бооцоо түр хасагдаж, А-гийн утас өрөө рүү автоматаар орно. Б өөрийн нээлттэй
   сорилттой байсан бол асуугаад түүнийг хаана. 3 асуулт, тус бүр 20 сек: хамгийн түрүүнд зөв
   хариулсан нь авна, буруу хариулсан нь тэр асуултад дахин хариулахгүй. Дуусахад ялагчид +бооцоо,
   ялагдагчид −бооцоо хоёр утсан дээр зэрэг харагдана (тэнцвэл бооцоо буцна).
   - Лобби дээр зөвхөн үүсгэгч нь яг одоо хүлээж буй (сүүлийн 15 сек-д лобби-гоо нээсэн) сорилт гарна.
     Үүсгэгч 10 минутаас удаан алга бол сорилт цуцлагдаж, код нь ажиллахаа больно (`GAME.DUEL`).
   - Код ч ижил түвшинд л ажиллана (`WRONG_TIER`); найзын сорилтыг id-аар хүлээн авах боломжгүй.
5. **Дэлгүүр** → дэвсгэр эсвэл хувцас сонгож оноогоор авахад шууд өмсөгдөж баавгай өөрчлөгдөнө (оноо серверээс хасагдана).
6. **Профайл хуваалцах:** А нүүрний зүүн дээд аватар дээр дарж **Миний профайл**-ыг нээнэ. 8 оронтой профайлын
   код («Хуваалцах» товч) гарна. Б мөн өөрийн профайл → **Найзын профайл** хэсэгт тэр кодыг бичээд А-гийн баавгайг
   (сонгосон дэвсгэр, хувцастай нь), шат, дараалал, хичээл бүрийн ахиц (сурах замын шат, ялсан boss, зөв хариулт),
   тулааны ялалт, цуглуулгыг харна.
   - Профайлыг зөвхөн кодоор олно (нэр, id-аар хайхгүй), нэвтэрсэн хүн л харна. Оноо, хамгаалалт зэрэг хувийн
     мэдээлэл харагдахгүй. «Код солих» дарвал хуучин код ажиллахаа болино.
   - Баавгайн дэвсгэр, хувцсыг сонгох бүрт апп серверт хадгалдаг (`PUT /me/look`, зөвхөн эзэмшиж буйгаа) тул бусдад
     ч ижил харагдана. API: `GET /me/profile`, `POST /me/profile/code`, `GET /profiles/:code`.
   - Вэб хувилбар дээр «Хуваалцах» нь `/u/<код>` холбоостой мессеж илгээнэ. Утсан дээр холбоос оруулах бол
     `mobile/.env`-д `EXPO_PUBLIC_WEB_URL=https://surgalt.pinequest-team1.workers.dev` гэж бичнэ (үгүй бол зөвхөн код).

### Ганцаараа турших (бот тоглогч)

```bash
cd api
npm run bot
```

Лобби дахь (Түвшин 1) эхний сорилтыг хүлээн авч, 2–8 секундэд хариулна.

```bash
npm run bot -- --create math --stake 3 --accuracy 0.6
```

Бот өөрөө сорилт үүсгэж урилгын кодыг хэвлэнэ; утаснаасаа хүлээн авна эсвэл кодоор орно. `--private` нэмбэл
лобби дээр гарахгүй (зөвхөн кодоор).

```bash
npm run bot -- --code 482913
```

Утсан дээр «Найзтайгаа» сорилт үүсгээд гарсан кодоор бот орно. Бусад сонголт: `--user`, `--grade`,
`--min`/`--max` (сек), `--loop`, `--url`.

## 5. Шалгалт

```bash
cd api
npm run typecheck
npm test
npm run e2e
```

- `npm test` — цэвэр функцүүдийн Vitest unit тест: UTC+8 өдрийн хил, streak, хамгаалалт, үржвэр,
  level, бооцооны хязгаар, LLM-ийн хариуны шалгалт, тулааны engine.
- `npm run e2e` — ажиллаж буй dev сервер дээр бүтэн урсгал: даалгавар, хамгаалалт ("цаг хугацаа"
  дуурайж), өдрийн хязгаар, дэлгүүр, профайл хуваалцах (код, бусдын профайл, баавгайн харагдац), бодит
  WebSocket-оор тулаан (ялалт, тэнцээ, 10 сек салалт), сурах бичгийн сан (түр хавтаснаас оруулах, дахин
  оруулах, хуудас солих/хасах, устгах), ledger-ийн нийлбэр. `-- --slow` нэмбэл 30 сек no-show-г бас
  шалгана; `-- --only tasks|shop|profiles|duel|books`.
- Mobile: `cd mobile && npm run typecheck`.

## 6. LAN-аар ажиллахгүй бол

1. Утас, компьютер нэг Wi-Fi-д байгаа эсэх (зочны Wi-Fi ихэвчлэн төхөөрөмжүүдийг хооронд нь хаадаг).
2. macOS Firewall: System Settings → Network → Firewall, `node`/`workerd`-д ирэх холболтыг зөвшөөрнө.
3. Утасны browser-оор `http://<IP>:8787/health` нээгдэж байгаа эсэх.
4. Wi-Fi солих бүрт компьютерийн IP өөрчлөгдөнө: `npx expo start -c`-г дахин асаагаад шинэ QR-ийг
   уншуулна (API-г дахин асаах шаардлагагүй). Expo буруу сүлжээний IP сонговол
   `REACT_NATIVE_PACKAGER_HOSTNAME=<IP> npx expo start -c`.
5. Expo Go "Project is incompatible" гэвэл утсан дээрх Expo Go-ийн SDK-тэй тааруулна
   (одоо SDK 58). Төслийг шинэ SDK руу шилжүүлэхдээ `npx expo install --fix` нэг нэгээр нь шинэчлэхэд peer
   зөрчил гардаг тул `npx expo install --check`-ийн бүх хувилбарыг `package.json`-д бичээд lock-ыг дахин үүсгэнэ.

**Нөөц хувилбар: workers.dev руу deploy** (Free plan хангалттай; DuelRoom нь SQLite-backed):

Багийн Cloudflare дээр тоглоомын DB `surgalt` ба сурах бичгийн сан `surgalt-books` аль хэдийн бий. Тэдгээрийн
id `wrangler.jsonc`-ийн `env.production`-д бичигдсэн тул `deploy`, `db:migrate:remote` хоёр тэр орчинд ажиллана
(дээд түвшний id-ууд зөвхөн local dev-д).

```bash
cd api
npx wrangler login
npm run db:migrate:remote
npx wrangler secret put ADMIN_TOKEN --env production
npm run deploy
```

`GEMINI_API_KEY` заавал биш (`npx wrangler secret put GEMINI_API_KEY --env production`): байхгүй бол
асуултын сан шинээр нөхөгдөхгүй, оруулсан асуултаараа ажиллана.

Шалгасан асуултын сан (ADMIN_TOKEN-оо өөрийнхөөрөө солино):

```bash
ADMIN_TOKEN=... npm run questions:import -- --url https://surgalt-api.pinequest-team1.workers.dev
ADMIN_TOKEN=... npm run lessons:import -- --url https://surgalt-api.pinequest-team1.workers.dev
```

`mobile/.env`: `EXPO_PUBLIC_API_URL=https://surgalt-api.pinequest-team1.workers.dev`. Утас Metro-д LAN-аар
хүрэхгүй бол `npx expo start --tunnel`. Deploy хийсэн Worker дээр background нөхөлт ~30 секундэд
багтах ёстой тул `wrangler.jsonc`-д `GEMINI_MODEL`-ийг `gemini-3.5-flash-lite` болгох нь найдвартай.

Free plan дээр нэвтрэхэд CPU хязгаарын алдаа (1102) гарвал `api/src/config/game.ts`-ийн
`PBKDF2_ITERATIONS`-ийг багасгана; hash бүр өөрийн iteration-ийг хадгалдаг тул хуучин хэрэглэгчид
нэвтэрсээр байна.

## 7. LLM (асуулт үүсгэлт)

- Provider: `LLM_PROVIDER` (`wrangler.jsonc` → `vars`). Хоосон бол `GEMINI_API_KEY` байвал Gemini,
  үгүй бол Workers AI. Background нөхөлт `GEMINI_MODEL` (анхдагч `gemini-3.8-flash`)-ийг ашиглана.
- **Free tier-ийн квот** (2026-10-20-нд ажигласан): `gemini-3.8-flash` өдөрт 20 хүсэлт; `gemini-3.6-flash`
  ч ойролцоо тоонд хүрээд зогссон; `gemini-3.5-flash-lite` илүү их квоттой. Ачаалалтай үед 503
  ("high demand") түр гардаг тул сервер `retryDelay`-ийг хүндэтгэж дахин оролддог.
- **Чанар** (асуулт бүрийг гараар шалгасан):
  - Түвшин 1-ийн 120 асуултаас 11-д flag тавьсан: 3 давхардал, үсгийн алдаатай нэр томьёо,
    "Ам алдах" хэлцийн буруу тайлбар гэх мэт.
  - Математик, физикийн хариу шалгасан бүх асуултад зөв байсан.
  - Монгол хэлний (дүрэм, хэлц, зүйр үг) асуулт хамгийн эмзэг:
    - `3.8-flash`, `3.6-flash` ~10–20%-д алдаатай;
    - `3.5-flash-lite` тэн хагаст нь алдаатай байсан тул түүний монгол хэлний бүх асуултад flag тавьсан.
  - Түвшин 3-ын монгол хэлэнд background нөхөлт `3.8-flash`-аар 40 асуулт нэмснээс шалгаад 31-ийг үлдээсэн
    (37 болсон). Түвшин 2-ын монгол хэл бага хэвээр (12). Квот сэргэхэд:
    `npm run seed:questions -- --subject mongolian --tier 2 --model gemini-3.8-flash,gemini-3.6-flash`.
- Загвар JSON-д `solution` (бодолт)-ыг `correctIndex`-ээс өмнө бичнэ. Сервер дараахыг шалгаж хаяна:
  - schema-д таарахгүй, кирилл текстгүй, 4 ялгаатай сонголтгүй асуулт;
  - нэг үг дотор латин, кирилл холилдсон ("зохиolyn") эсвэл өөр бичгийн үсэг ("ە") орсон асуулт;
  - тоо, үйлдлээрээ ижил бодлого (жишээ нь `2.4:0.6+1.5`).

  Үлдсэн асуултын сонголтуудыг холино. Хадгалах бүтэц нь `{ prompt, options[4], correctIndex, explanation }`.
- Pool босгоос доош орвол (хэрэглэгчийн хараагүй асуулт < 15 эсвэл нийт < 30) background-д 20
  асуултаар нөхнө. Тулааны асуултыг хурдны тулд зөвхөн pool-оос авна.
- Утсан дээрх "Асуулт буруу байна" товч асуултыг flagged болгож, дахин гаргахгүй (зөвхөн тухайн хүнд гарсан асуултыг). Андуурсан бол
  `POST /admin/questions/:id/unflag` (`X-Admin-Token`).
- Workers AI local dev-д ч Cloudflare руу ханддаг тул `npx wrangler login` хийгээд `npm run dev:ai`.

### Баавгайтай ярилцах (Gemini Live)

Хүүхэд алдсан бодлогынхоо сэдвийг баавгайтай монголоор дуугаар ярилцана. `GEMINI_API_KEY` заавал хэрэгтэй.
Түлхүүргүй үед апп "Баавгай одоо ярих боломжгүй" гэж харуулна.

- **Хаанаас эхлэх вэ:** буруу хариулсны дараа "Баавгайгаас асуух" товч (тухайн бодлогоор), эсвэл шагналын
  дэлгэц дээрх "Алдсан бодлогоо баавгайтай ярилцах" товч (сүүлд алдсан 5 бодлогоор). Аль нь ч `/tutor` дэлгэцийг нээнэ.
- **Холболт:** `GET /tutor/ws` WebSocket нь утас ↔ Worker ↔ Gemini Live-ийг холбоно (`api/src/routes/tutor.ts`).
  - Түлхүүр болон system prompt (бодлого, хүүхдийн хариулт, зөв хариу, тайлбар) серверээс гарахгүй.
  - Хүүхэд хараахан хариулаагүй бодлогоор ярилцлага эхлүүлж болохгүй (404).
  - Даалгаварт 2+ алдсан (давтлага дуусаагүй) бодлогын зөв хариу, тайлбарыг prompt-д өгөхгүй: баавгай сэдвийг
    заах ч хариуг хэлж чадахгүй, хүүхэд давтлага дээр өөрөө бодно.
- **Хязгаар:** нэг хэрэглэгч өдөрт `GAME.TUTOR.DAILY_SESSIONS` (10) ярилцлага, зэрэг `MAX_ACTIVE` (2)-оос олныг нээхгүй
  (`tutor_sessions`, migration `0009`). Gemini-тэй холбогдож амжаагүй ярилцлага тоологдохгүй.
- **Загвар:** `wrangler.jsonc` → `GEMINI_LIVE_MODEL` (анхдагч `gemini-3.8-live`).
- **Тогтмол утгууд:** хоолой, ярианы дээд хугацаа (5 мин) нь `GAME.TUTOR`-д. Prompt нь `api/src/llm/live.ts`-д.
- **Баавгайн дуу (`GAME.TUTOR.SPEECH`):** env-ийн `TUTOR_SPEECH` (`tts` | `live`) үүнийг дарна, жишээ нь local дээр
  `.env.local`-д `TUTOR_SPEECH=tts`, production-д `wrangler.jsonc`-ийн `vars`.
  - `'live'` (анхдагч): Live өөрөө ярина. Хамгийн хурдан, өдрийн хязгааргүй.
  - `'tts'`: Live хүүхдийг сонсож бодно, хэлэх үгийг нь (transcript) `GEMINI_TTS_MODEL` (`gemini-3.8-flash-lite-tts`)
    илүү байгалийн аялгаар дуу болгоно (`api/src/llm/tts.ts`, `speech.ts`). Хариу ~1 сек хойно ирнэ.
    - Live текст гаргадаггүй тул Live-ийн дууг хаяж, транскриптийг нь ашиглана. Ээлж бүрт 2 TTS хүсэлт: эхний
      хэсгийг (өгүүлбэр, таслал эсвэл 4 үг) шууд, үлдсэнийг `generationComplete` ирэхэд.
    - TTS-ийн хязгаар: үнэгүй багцад өдөрт 10, billing-тэй Tier 1-д загвар бүрт өдөрт 100 хүсэлт. Billing нь бүхэл
      төсөлд (Live-д ч) үйлчилдэг тул өөр төслийн billing-тэй түлхүүрийг `GEMINI_TTS_API_KEY`-д тавибал Live үнэгүй
      түлхүүрээр (`GEMINI_API_KEY`) үлдэнэ. Үнэгүй багцын өгөгдлийг (хүүхдийн дуу) Google бүтээгдэхүүнээ
      сайжруулахад ашигладгийг анхаарна.
    - TTS алдаа гарвал (429) тэр ярилцлагын үлдсэн хэсэгт Live-ийн дуугаар үргэлжлүүлнэ. Өдрийн квот дууссан бол
      сервер Google-ийн заасан хугацаа хүртэл TTS-ийг оролдохгүй.
- **Хэл:** `GAME.TUTOR.LANGUAGE` (`mn-MN`) нь яриаг таних ба баавгайн ярих хэлийг тогтооно. Үүнгүйгээр чимээтэй
  үед хүүхдийн яриаг англи, герман хэлээр бичдэг байсан. Энэ нь хатуу хязгаар биш тул өөр бичгээр гарсан
  транскриптийг сервер дэлгэцэнд харуулахгүй. Баавгай дууг өөрөө сонсдог тул ойлголтод нөлөөлөхгүй.
- **Дуу:** утас `expo-audio`-ийн `useAudioStream`-аар mic-ийн PCM (16 kHz) илгээж, баавгайн PCM (24 kHz)-ийг WAV
  хэсэг болгон тоглуулна. Энэ нь Expo Go-д ажиллана (`mobile/src/hooks/useBearTalk.ts`).
- **Ээлжлэн ярих:** iOS дээр mic, тоглуулалт хоёр зэрэг ажилладаггүй, echo ч гардаг. Тиймээс баавгай ярих
  үед mic унтарч, ярьж дуусмагц автоматаар асна. Хүүхэд "Би ярья" товчоор баавгайг тасалж болно.

## 11. Сурах бичгийн сан (local)

Сурах бичгийн хуудас бүрийг файлаар нь хадгалах сан. Одоохондоо компьютер дээрээ (local) ажиллана, дараа
нь багийн Cloudflare руу шилжүүлнэ.

- **Мэдээлэл** (ном, хуудас, дараа нь OCR текст): тусдаа D1 database `surgalt-books` (`BOOKS` binding,
  schema `api/migrations-books/`). Тоглоомын `surgalt` DB-д хүрэхгүй.
- **Хуудасны файл:** R2 bucket `surgalt-books` (`BOOK_FILES`). Local-д `api/.wrangler/state` дотор хадгалагдана.
- **Эх файл:** `api/books/<хавтас>/` — git-д орохгүй (repo public, зохиогчийн эрх). Сан устсан ч
  (`db:reset`) эндээс `books:import`-оор дахин үүснэ. Хавтасны бүтэц, `book.json`: `api/books/README.md`.

### Анх удаа: сан үүсгэх

```bash
cd api
```

```bash
npm run db:migrate
```

Дутуу migration-ийг л нэмнэ: одоо байгаа хэрэглэгч, асуулт устахгүй. Сервер ажиллаж байсан бол шинэ кодыг
найдвартай уншуулахын тулд зогсоогоод (`Ctrl+C`) `npm run dev`-ээр дахин асаана.

### Ном оруулах (ном бүрт)

1. `api/books/` дотор `<хичээл>-<анги>` нэртэй хавтас үүсгэнэ: `mongolian-7`, `math-6`, `physics-9`.
2. Файлаа хийнэ. Хуудасны дараалал = файлын нэрийн дараалал (`2.jpg` < `10.jpg`):
   - биет номын скан: `mongol7.pdf` (эсвэл бүлгээр `01.pdf`, `02.pdf`…);
   - онлайн хувилбарын зураг: `001.jpg`, `002.jpg`… (pdf, jpg, png, webp).
3. Сервер ажиллаж байх ёстой: өөр terminal-д `npm run dev` (эсвэл VS Code-ийн "API сервер" task).
4. Хуудасны дарааллыг шалгана (юу ч оруулахгүй):

   ```bash
   npm run books:import -- --book mongolian-7 --dry
   ```

5. Сан руу оруулна:

   ```bash
   npm run books:import -- --book mongolian-7
   ```

   Анх удаа хавтасны нэрээс `book.json` үүснэ. Он, хэвлэлийн газар, `pageOffset`-ийг засаад дахин
   ажиллуулна: өөрчлөгдөөгүй хуудсыг дахин илгээхгүй, зөвхөн мэдээлэл шинэчлэгдэнэ. `--book`-гүй бол
   `api/books/` доторх бүх номыг оруулна.
6. Шалгана: номын жагсаалт, дараа нь нэг хуудсыг сангаас гаргаж нээх (жишээ нь 45-р хуудас):

   ```bash
   npm run books:list
   ```

   ```bash
   npm run books:page -- --book mongolian-7 --page 45
   ```

Хуудас солих, нэмэх, хасах: хавтас дахь файлаа өөрчлөөд 5-р алхмыг давтана. Өөрчлөгдсөн хуудас л
шинэчлэгдэж, хассан хуудас сангаас устна. Номыг сангаас бүхэлд нь устгах (хавтас хэвээр үлдэнэ):

```bash
npm run books:delete -- --book mongolian-7
```

API: `GET /admin/books`, `GET /admin/books/<хавтас>` (хуудасны жагсаалт), `GET /admin/books/<хавтас>/pages/<дугаар>`
(файл), `.../pages/<дугаар>/text` (текст), бүгд `X-Admin-Token`-тэй.

### Хуудасны текст

`books:import` хуудас бүрийн текстийг PDF-ийн текст давхаргаас Gemini-гүйгээр, үнэгүй гаргана. Хуучин
"Mon" фонтоор эвдэрсэн үгсийг (`Ìàòåìàòèê` → `Математик`) засаж, текстийг `api/books/<хавтас>/text/0045.md`-д
хадгалаад санд оруулна. Хуудас бүрийн чанар нь сайн, муу (эвдэрсэн тэмдэгт олонтой) эсвэл хоосон (текст
давхаргагүй, зураг) гэж тэмдэглэгдэнэ.

Текст давхаргад томьёо (бутархай, язгуур, олонлогийн тэмдэг) ихэвчлэн байдаггүй. Муу, хоосон хуудсыг,
эсвэл томьёо хэрэгтэй бол бүх хуудсыг Gemini-ээр уншуулна (томьёог LaTeX-ээр бичнэ). Сервер ажиллаж,
`.env.local`-д `GEMINI_API_KEY` байх ёстой:

```bash
npm run books:ocr -- --book math-6 --model gemini-3.8-flash,gemini-3.6-flash,gemini-3.5-flash-lite
```

- Анхдагчаар зөвхөн муу, хоосон хуудсыг уншина. `--all` бол бүх хуудсыг, `--pages 35-40,92` бол заасан хуудсыг.
- Нэг хүсэлтэд 4 хуудас (`--batch`, дээд тал нь 8) явуулдаг бөгөөд ~2–3 минут үргэлжилнэ. Эхний загварын өдрийн
  квот дуусахад `--model`-ийн дараагийнх руу шилжинэ. Дахин ажиллуулахад аль хэдийн уншсан хуудсаа алгасна.
- Уншсан текст `text/`-д хадгалагддаг тул `db:reset`-ийн дараа `books:import` квот зарцуулахгүйгээр сэргээнэ.
- Хуудасны текстийг харах: `npm run books:page -- --book math-6 --page 34 --text`. `text/0034.md`-г гараар
  засаад `books:import` ажиллуулбал засвар санд орно.

### Сангаас асуулт үүсгэх

Асуулт үүсгэх бүх зам (`seed:questions`, background нөхөлт, `/admin/generate`) сангаас ажиллана. Санд тухайн
хичээл, түвшний ном байвал Gemini-д сангийн 2 дараалсан хуудасны текстийг өгч, асуултыг зөвхөн түүнд үндэслэн
зохиолгоно. Дасгалыг хуулахгүй: тоо, нэр, нөхцөлийг өөрчилнө. Хамгийн бага ашиглагдсан хуудсыг түрүүлж сонгодог
тул номын бүх сэдэв жигд хамрагдана. Асуулт аль хуудаснаас гарсныг `questions.book_ref`-д дотооддоо хадгалдаг.
**Апп-д эх сурвалж, хуудас харагдахгүй.**

- Одоо санд Математик 6–9 байгаа тул Түвшин 1–2-ын математик сангаас үүснэ. Монгол хэл, Физик, Түвшин 3 (10-р анги)
  хөтөлбөрийн сэдвийн жагсаалтаар үүснэ. Ном нэмэхэд автоматаар сангаас болно.
- Gemini-д ямар хэсэг очихыг харах: `npm run books:excerpt -- --tier 1 --subject math`.
- Сангүйгээр үүсгэх бол: `npm run seed:questions -- --no-books`.
- Энэ шинэчлэлтийг татсны дараа нэг удаа `npm run db:migrate` (questions-д `book_ref` багана нэмнэ).

### Багийн Cloudflare дээрх сан

wrangler зөв account-ыг сонгоно.

**Шинэ гишүүн нэмэх (account-ын эзэн):** Cloudflare dashboard → Manage Account → Members → Invite. Гишүүний имэйлийг
оруулаад **Administrator** эрх өгнө (Workers, D1, R2-д бичих эрхтэй; төлбөрийн тохиргоонд хүрэхгүй). Гишүүн
имэйлээр ирсэн урилгыг баталгаажуулаад өөрийн компьютер дээр:

```bash
npx wrangler login
```

```bash
npm run dev:books
```

`dev:books` горимд тоглоомын DB local хэвээр, сан (`BOOKS`, `BOOK_FILES`) нь Cloudflare дээрх жинхэнэ сан байна

Сангийн schema шинэчлэгдвэл (`migrations-books/`): `npm run books:migrate:remote`.

## 12. Офлайн горим

Сервер хүрэхгүй үед (интернэтгүй, сервер унтарсан) апп офлайн горимд орно. Хүүхэд XP, оноо, дараалал цуглуулахгүй тул
онлайн болоход серверт юу ч илгээж тааруулахгүй.

- **Хэзээ офлайн болох:** `api()`-ийн хүсэлт сүлжээний алдаа (`NETWORK`, `TIMEOUT`) өгвөл офлайн, ямар нэг хариу ирвэл
  онлайн (`mobile/src/lib/online.ts`). Офлайн үед апп 20 сек тутам, мөн апп нээгдэх бүрт серверийг шалгаж, хүрмэгц
  профайлаа шинэчилнэ.
- **Өөрөө асаах:** интернэттэй ч «Хуанли ба профайл» дэлгэцийн «Офлайн горим» toggle-оор шилжинэ. Тэр үед `api()`
  сервер рүү хүсэлт илгээхгүй (`OFFLINE` алдаа), апп интернэтгүй үеийнхтэй яг адил ажиллана, серверийг үе үе шалгахгүй.
  Сонголт апп хаагдсан ч хадгалагдана, гарахад унтарна. Унтраамагц профайл серверээс шинэчлэгдэнэ.
- **Нээгдэх хэсэг:** Нүүр, профайл (хуанли) нь сүүлд ирсэн профайлаар (`mobile/src/lib/cache.ts`) харагдана. Апп
  интернэтгүй нээгдсэн ч өмнө нь нэвтэрсэн бол шууд орно; огт нэвтэрч байгаагүй бол хуучин «Сервертэй холбогдож
  чадсангүй» дэлгэц гарна.
- **Даалгавар:** офлайн дасгал болно. Асуултыг апп доторх сангаас (`mobile/src/lib/offline/questions.json`) хүүхдийн
  түвшин, ангиар сонгож, хариуг утсан дээр шалгана. Дүнгийн дэлгэцэд зөвхөн зөв хариултын тоо гарна. «Асуулт буруу
  байна», «Баавгайгаас асуух» нуугдана. Даалгаврын дунд сүлжээ тасарвал «Офлайн дасгал хийх» товч гарна.
- **Дэлгүүр:** хувцас, дэвсгэрийг үзэж, авсан зүйлсээ сонгоно. Худалдан авах, streak хамгаалалт авах нь идэвхгүй.
- **Түгжигдэх хэсэг:** Сурах зам, Баг (тулаан) бүдгэрч дарагдахгүй. Тэдгээр дээр байхад офлайн болбол Нүүр рүү шилжинэ.
  Boss тулаан ч онлайн үед л.
- **Асуултын санг шинэчлэх:** `api/seed/questions.json`, `lesson-questions.json` өөрчлөгдсөний дараа `mobile/`-д:

```bash
npm run offline:questions
```
