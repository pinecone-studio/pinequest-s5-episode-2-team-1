# Номын хавтас (сурах бичгийн сангийн эх файлууд)

Ном бүрийг энд тусдаа хавтсаар хийнэ. Энэ README-ээс бусад бүх файл **git-д орохгүй** (`.gitignore`):
repo public тул сурах бичгийн скан, зургийг GitHub руу оруулж болохгүй (зохиогчийн эрх). Багийн гишүүнтэй
хавтсаа zip-лээд (Drive гэх мэт) хуваалцана.

```
books/
  mongolian-7/          ← хавтасны нэр = <хичээл>-<анги>[-он]: math-6, physics-9, math-10-2019
    book.json           ← анх оруулахад хавтасны нэрээс автоматаар үүснэ
    mongol7.pdf         ← биет номын скан (бүлгээр хуваасан бол 01.pdf, 02.pdf …)
  math-6/
    001.jpg 002.jpg …   ← онлайн хувилбараас авсан хуудасны зураг
```

- **Хуудасны дараалал = файлын нэрийн дараалал.** Тоог тоогоор нь эрэмбэлнэ (`2.jpg` < `10.jpg`).
  PDF-ийн хуудас бүр тусдаа хуудас болно. Зураг, PDF холилдож болно.
- **Файлын төрөл:** pdf, jpg, png, webp. HEIC/TIFF бол jpg болгоно:
  `sips -s format jpeg scan.heic --out scan.jpg` (macOS).
- **Скан:** 300 DPI, хуудас тэгш, хуудасны дугаар харагдаж байх. Нэг хуудас 30MB-аас ихгүй.

## book.json

```json
{
  "subject": "mongolian",
  "grade": 7,
  "title": "Монгол хэл 7",
  "year": 2023,
  "publisher": null,
  "source": "scan",
  "pageOffset": 2
}
```

| Талбар | Утга |
|---|---|
| `subject` | `math`, `mongolian`, `physics` (латин жижиг үсгээр) |
| `grade` | 1–12 |
| `title` | номын нэр |
| `year`, `publisher` | хэвлэгдсэн он, хэвлэлийн газар (мэдэхгүй бол `null`) |
| `source` | `scan` = биет номын скан, `web` = онлайн хувилбарын зураг |
| `pageOffset` | хэвлэмэл 1-р хуудсын өмнөх хуудасны тоо (нүүр, гарчиг…). 3 дахь файл нь "1" гэсэн дугаартай бол `2` |

Оруулах, шалгах командууд: үндсэн [README](../../README.md)-ийн "Сурах бичгийн сан" хэсэг.
