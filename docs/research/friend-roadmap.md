# Судалгаа: найзынхаа сурах зам дээр хаана явааг харах

Огноо: 2026-10-28. Зорилго: найз болсон хоёр хүүхэд бие биенийхээ сурах зам (газрын зураг) дээр хаана явааг харах
боломжийг одоогийн кодонд хэрхэн нэмэхийг тодорхойлох. Энэ баримт зөвхөн судалгаа, код өөрчлөөгүй.

## 1. Одоо байгаа зүйлс

### Өгөгдөл (API, D1)

| Хүснэгт | Юу хадгалдаг | Хаана уншдаг |
|---|---|---|
| `friendships` (0016) | `from_id`, `to_id`, `status` = `pending` / `accepted` | `api/src/services/friends.ts` |
| `subject_progress` (0011, 0018) | хичээл бүрийн `xp`, `nodes` (давсан зангилаа), `bosses_beaten` (давсан хаалга) | `loadSubjectPaths` (`api/src/services/users.ts:104`) |
| `node_stages` (0021) | зангилаа бүрийн давсан шат (1–3 од) | мөн `loadSubjectPaths` |
| `chests` (0027) | нээсэн нууц хайрцаг | мөн `loadSubjectPaths` |

`loadSubjectPaths(db, userId)` нь `SubjectPath` (`shared/types.ts:149`)-ийг **дурын** хэрэглэгчийн хувьд буцаадаг тул
найзынх ч мөн адил уншигдана. Шинэ хүснэгт, migration хэрэггүй.

### Одоо бусдад харагдаж буй ахиц

- `GET /profiles/:code` → `PublicProfile.skills[]`: хичээл бүрийн `level` (= `nodes + 1`) ба ялсан жинхэнэ boss-ын тоо.
  Энэ нь **кодыг мэдэх хэн бүхэнд** харагддаг, найз эсэхээс үл хамаарна.
- `GET /friends` → `FriendDto`: нийт XP-ийн шат (`level`), streak, баавгайн төрх. Хичээлийн замын байрлал байхгүй.

### Газрын зургийн тооцоо (`shared/path.ts`)

- Замын урт `n = pathLessons(bookLessons)` нь **хүүхдийн ангийн сурах бичгээс** хамаарна
  (`GET /me/lessons/:subject` → `loadLessons(env, subject, user.grade)`). Ном байхгүй бол 24.
- Одоогийн зангилаа = `currentNode(n, level, bossesBeaten)`: шат ба давсан хаалганаас тооцно, давж амжаагүй хаалганы
  дэргэд зогсоно.
- Иймээс **өөр ангийн найзын зам өөр урттай, өөр сэдэвтэй**. Миний газрын зураг дээр түүнийг шууд байрлуулж болохгүй;
  түүний `n`-ээр тооцох ёстой.

### Апп (mobile)

- `PathMap` (`mobile/src/components/PathMap.tsx`) нь цэвэр props-оор ажилладаг (`layout`, `current`, `stages`, `beaten`,
  `lessons`, `chests`, `onNodePress`, `onChest`, `selected`) тул өөр хүний өгөгдлөөр дахин ашиглаж болно.
- Найзын профайл: `mobile/src/app/u/[code].tsx` (найз бол `data.friend === 'friends'`).
- Найзын жагсаалт: `mobile/src/app/profile.tsx`, мөр нь `FriendRow`.

## 2. Боломжит хувилбарууд

### A. Найзын жагсаалт / профайл дээр товч ахиц (хамгийн хялбар)

Найзын мөр эсвэл профайл дээр «Математик · 3-р бүлэг · 12/28 · 2 boss» гэх мэт мөр ба жижиг progress bar.

- API: `FriendDto`-д `paths: Record<Subject, { node: number; total: number; unit: number; bossesBeaten: number }>`
  нэмнэ. `listFriends` дотор найзуудын `subject_progress`-ийг нэг query-ээр (`WHERE user_id IN (...)`) уншина.
  `total`, `node`-ыг сервер найзын ангийн номын хичээлийн тоогоор тооцно (`pathLessons`, `currentNode`).
- Апп: `FriendRow`-д нэг мөр нэмнэ.
- Ажил: ~0.5 өдөр. Эрсдэл бага.

### B. Найзын газрын зургийг харах (read-only)

Найзын профайлаас «Замыг нь харах» товч → `/u/[code]/path?subject=math` дэлгэц: найзын газрын зураг, түүний баавгай
одоогийн зангилаан дээр, од, ялсан boss-ууд. Дарахад даалгавар эхлэхгүй, зөвхөн хичээлийн нэр харагдана.

- API (шинэ): `GET /friends/:code/path/:subject` →
  `{ name, look, grade, path: SubjectPath, lessons: BookLesson[] }`. Зөвхөн `friendStatus === 'friends'` үед, бусад
  тохиолдолд 403 `NOT_FRIENDS`. `lessons` нь найзын ангийн (`loadLessons(env, subject, friend.grade)`).
- Апп: `PathMap`-ийг дахин ашиглана. `onNodePress` нь зөвхөн хичээлийн нэрийг харуулна, `onChest` хоосон, хайрцаг
  нээх боломжгүй. Дэлгэцийн scroll/төвд голлуулах логикийг `(tabs)/path.tsx`-ээс `usePathScroll` hook болгон гаргаж
  хуваалцвал давхардал багасна.
- Ажил: ~1.5–2 өдөр.

### C. Миний газрын зураг дээр найзуудын баавгай (хамгийн «тоглоом»-той)

Өөрийн замаа харж байхад найзуудын жижиг баавгайн толгой тэдний зангилаан дээр харагдана («Болд чамаас 3 алхам
түрүүлж байна»). Duolingo-гийн найзын leaderboard-оос илүү урам өгдөг.

- Зөвхөн **ижил ангийн** (ижил ном, ижил `n`) найзуудыг байрлуулна. Өөр ангийнхныг харуулахгүй, эсвэл тэдний замын
  хувиар (`node / total`) ойролцоо байрлуулна (буруу ойлгогдож болзошгүй тул эхэндээ хийхгүй байхыг санал болгоно).
- API (шинэ): `GET /friends/paths/:subject` → `[{ code, name, look, node, bossesBeaten }]`, зөвхөн надтай ижил
  ангийн найзууд. Нэг query: `friendships JOIN users JOIN subject_progress WHERE grade = ?`.
- Апп: `PathMap`-д `friends?: { node, look, name }[]` prop нэмж, зангилааны хажууд жижиг `Avatar` (нэг зангилаанд
  олон бол «+2»). Дарахад `/u/<code>` руу.
- Ажил: ~1.5 өдөр (B-тэй хамт хийвэл API-ийн тооцоо хуваалцана).

## 3. Нууцлал ба аюулгүй байдал

Хэрэглэгчид 6–12-р ангийн хүүхдүүд тул:

1. **Зөвхөн `accepted` найз** замыг харна. Шалгалтыг сервер дээр (`friendStatus`) хийнэ, аппын нуулт хангалтгүй.
2. **Хувийн мэдээлэл орохгүй:** оноо, амь, цүнх, хариултын зөв/буруу, асуултын текст, user id буцаахгүй
   (`PublicProfile`-ийн зарчимтай ижил). Байрлал, од, boss-ын тоо л.
3. **Онлайн / «яг одоо» мэдээлэл өгөхгүй** (хэзээ хичээл хийснийг харуулахгүй). Хэрэгтэй бол дараа нь тусад нь шийднэ.
4. Одоо `PublicProfile.skills` найз биш хүнд ч шатыг харуулдаг. Найзын онцлог гарахад үүнийг ч найзуудаар
   хязгаарлах эсэхийг багаараа шийдэх (санал: хязгаарлах).
5. Найзаас хасахад мөр устдаг тул эрх шууд алга болно, нэмэлт ажил хэрэггүй.
6. (Заавал биш) Тохиргоонд «Найзууд маань миний замыг харна» унтраалга. PoC шатанд хэрэггүй гэж үзэж байна.

## 4. Гүйцэтгэл

- Найзын тоо ≤ 100 (`GAME.FRIENDS.MAX`). Найз бүрт `loadSubjectPaths` дуудахгүй, нэг `IN (...)` query эсвэл JOIN.
- Найзын ангийн номын хичээлийг `loadLessons` нь ном бүрээр уншдаг: ангиар нь бүлэглэж, нэг анги нэг л удаа.
- Хариу жижиг (найз бүр ~5 тоо) тул cache хэрэггүй. Аппад `useFocusEffect`-ээр дэлгэц нээгдэх бүрт шинэчилнэ.

## 5. Санал болгох дараалал

1. **A** (жагсаалт дээр товч ахиц) — хурдан, найзын онцлогийг шууд үнэ цэнтэй болгоно. Серверийн
   `friendPathSummary(db, env, friendIds)` функц дараагийн алхмуудад дахин ашиглагдана.
2. **B** (найзын газрын зураг) — «хаана явааг харах» хүсэлтийг бүрэн хангана.
3. **C** (миний зураг дээр найзуудын баавгай) — урам, өрсөлдөөн. Ижил ангийн найзаар хязгаарлана.
